# Suggested 3–5 minute walkthrough

Record a screen-share locally; this outline is not a recorded video.

1. **0:00–0:35 — Setup and roles:** show the README, sign in as the admin demo account, and point out the four role-specific login options.
2. **0:35–1:20 — Academic administration:** show Grade 8 / Section A, its assigned teacher and Mathematics subject. Open the student list and explain the synthetic Sam Rivera record.
3. **1:20–2:10 — Attendance and authorization:** sign in as the teacher, record attendance for the assigned student/session, retry the same entry to show the conflict response, and explain section-scoped server checks.
4. **2:10–2:55 — Results and privacy:** enter/view an exam result and show the report card. Sign in as the guardian and show the linked student's details; demonstrate that another student ID is denied if a second synthetic student is available.
5. **2:55–3:45 — Fee ledger and audit:** create an invoice as admin, sign in as guardian to record a simulated partial payment, then show paid/due reconciliation and audit events.
6. **3:45–4:15 — Engineering evidence:** show `npm test`, the migration/schema and API documentation, then state the local-only deployment and known gaps.

Do not show `.env`, personal records, browser password managers or real payment information in the recording.
